## Technical SEO included
- Unique `<title>` + meta description per page (7 pages)
- Canonical URLs, robots index/follow, geo meta tags
- Open Graph + Twitter card tags
- Schema.org `FoodEstablishment` / `Caterer` JSON-LD with address, phone, hours, area served, cuisines and services
- Descriptive alt text on dish images, semantic H1/H2 structure
- Mobile-responsive, single-file pages (fast load)
- Google Maps embed with NAP (name, address, phone) consistent across site and footer
